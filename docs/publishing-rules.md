# Publishing rules

- Default visibility: **private**.
- A folder goes public only with: README, one diagram, sanitized source, 90-second demo link.
- No customer names, plant IPs, badges, or screenshots with company tags.
- No license files, VPN configs, or Windows images from lab PCs.
- Videos: unlisted YouTube or Drive. Do not git large binaries.
- LinkedIn posts only after the recover-from-fault loop works on camera.
